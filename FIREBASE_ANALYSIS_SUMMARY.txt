## 💾 Database Structure (Verified Correct)

```
Firestore Project: bahay-kusina-main
│
├── meals/ (1000+ items possible)
│   └── {mealId}
│       ├── type: string
│       ├── title: string
│       ├── vendor: string
│       ├── vendorId: string ← Used for queries
│       ├── price: number ← Must be number, not string
│       ├── left: number ← Stock quantity
│       ├── imageUrl: string
│       ├── createdAt: timestamp ← Server timestamp
│       └── updatedAt: timestamp
│
├── orders/ (100k+ orders possible)
│   └── {orderId}
│       ├── orderDate: timestamp
│       ├── vendorId: string ← Query index needed
│       ├── customerId: string
│       ├── status: string (pending, confirmed, preparing, etc.)
│       ├── totalAmount: number
│       ├── items: array
│       └── (+ 5 more fields)
│
└── users/ (10k+ users possible)
    └── {userId}
        ├── fullName: string
        ├── email: string
        ├── userType: string (vendor or customer)
        ├── profileImageUrl: string
        └── orders/ (subcollection)
            └── (copy of orders collection for user)
```
